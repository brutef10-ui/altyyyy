# al present

Презентация показывается на одном устройстве (экран), а листается с другого (пульт — телефон).

- `/screen.html` — экран: комната, библиотека презентаций, показ.
- `/remote.html` — пульт: кнопки «назад» и «вперёд».

Поддерживаются PDF, картинки и презентации Canva по ссылке.

## Запуск

```
npm install
npm start
```

На Render: **Build Command** `npm install`, **Start Command** `npm start`.
Загруженные файлы хранятся в папке `data/`. Чтобы они не пропадали при каждом деплое, подключите
Persistent Disk с путём `/opt/render/project/src/data`.

## Видео на слайдах

На слайде с видео первое нажатие «вперёд» включает видео, второе — переключает на следующий слайд.
«Назад» во время видео останавливает его.

Видео можно прикрепить к любому слайду вручную (кнопка «Видео» у презентации), а для Canva — получить
автоматически (см. ниже).

## Canva: слайды и видео автоматически

Если подключить Canva API, достаточно вставить ссылку на презентацию: сайт сам забирает слайды,
сам находит слайды с видео и сам подставляет видео. Число слайдов вводить не нужно.

Как сайт находит видео: Canva выгружает обычный слайд в MP4 ровно на 5 секунд, а слайд с видео —
на длину видео. Поэтому видео ровно в 5 секунд не определится — его можно прикрепить вручную.

### Настройка (один раз)

1. Откройте [портал разработчика Canva](https://www.canva.com/developers/integrations) и создайте
   интеграцию для **Connect API** (Canva может попросить включить двухфакторную защиту аккаунта).
2. В настройках интеграции:
   - скопируйте **Client ID** и создайте **Client secret**;
   - в разделе прав (Scopes) включите чтение дизайнов: `design:meta:read` и `design:content:read`;
   - в разделе Authentication добавьте Redirect URL:
     `https://<ваш-адрес>.onrender.com/canva/callback`
     (точный адрес показан на экране сайта под полем для ссылки Canva).
3. На Render в разделе **Environment** добавьте переменные:
   - `CANVA_CLIENT_ID` — Client ID;
   - `CANVA_CLIENT_SECRET` — Client secret;
   - `PUBLIC_URL` — необязательно, адрес сайта, например `https://<ваш-адрес>.onrender.com`.
4. Перезапустите сервис, откройте экран и нажмите **«Подключить Canva»**.

Презентация должна быть в том аккаунте Canva, который подключён к сайту. Загрузка занимает
пару минут: на каждый слайд Canva готовит отдельный файл.

Без подключения Canva ссылка тоже работает, но презентация показывается встроенным окном Canva:
видео в нём не включаются с пульта, а число слайдов нужно указать вручную.
