# Умный перекрёсток — симуляция

Открыть `simulation/index.html` в браузере (сервер не нужен, всё в одном файле).

Перекрёсток с четырьмя подъездами, по одной полосе в каждую сторону, машины едут прямо.
Светофор переключает две фазы: Запад–Восток и Север–Юг (3 с жёлтого + 2 с «всем красный»).

- **Обычный светофор** — фиксированный цикл 30/30 с. В час пик он не успевает пропускать
  загруженное направление, хвост растёт и уходит за край кадра.
- **ИИ-регулировщик** — кнопка вверху. Камера на каждом подъезде смотрит на 130 м навстречу потоку,
  распознаёт машины, меряет очередь (сколько машин и сколько метров) и считает интенсивность потока.

## Как ИИ решает, сколько давать зелёного

1. **Порог затора («перегородка»)** — линия на заданном расстоянии от стоп-линии (по умолчанию 60 м).
   Если хвост очереди за порогом и это направление заметно тяжелее пересекающего — оно получает приоритет.
2. **Нужное время зелёного**: `g = (3 с + N · 2 с) / (1 − λ · 2 с)`, где N — машин в очереди,
   λ — интенсивность подъезда (маш/с), 2 с — интервал разъезда одной машины.
3. **Постепенность**: от цикла к циклу зелёный меняется не больше чем на +8 / −6 с.
   Пробка рассасывается за несколько циклов, а не рывком, и пересекающее направление не «умирает».
4. **Ограничения безопасности**: зелёный 10–45 с, с приоритетом до 70 с; если кто-то ждёт дольше 90 с —
   фаза переключается принудительно.
5. **Досрочное переключение**: если очередь разъехалась и к стоп-линии никто не подъезжает,
   остаток зелёного отдаётся другой стороне.

Все решения с причинами пишутся в блок «Решения ИИ».

## Цифры для презентации

```
node simulation/benchmark.mjs            # сводка по трём сценариям
node simulation/benchmark.mjs --verbose  # поминутно: 10 мин обычный светофор, потом ИИ
```

Движок берётся прямо из `index.html`. Среднее за последние 10 из 30 минут, 5 случайных потоков:

| Сценарий | Ждут (обычный → ИИ) | Средняя задержка | Макс. очередь |
|---|---|---|---|
| Час пик с запада | 122 → 12 машин (−90%) | 144 → 26 с (−82%) | 710 → 47 м (−93%) |
| Час пик с севера | 118 → 9 машин (−92%) | 145 → 21 с (−86%) | 731 → 34 м (−95%) |
| Равномерный поток | 7,6 → 5,7 машин (−25%) | 21 → 17 с (−20%) | 33 → 23 м (−32%) |

Модель движения — Intelligent Driver Model; параметры подобраны так, что очередь разъезжается
≈2 с на машину (1800 машин в час с полосы, как на реальных перекрёстках).
